# 私有扩展

这个目录是给「我要用，但不打算给别人」的脚本准备的。

`.gitignore` 里的规则是：

```gitignore
private/*
!private/README.md
```

也就是：**目录里的任何东西都不会进 git**，只有这份说明会被提交。你自己 clone 下来、往里放脚本，`git status` 永远是干净的；别人 clone 下来看到的是一个空目录加这份说明。

## 为什么需要它

公开仓库有一条界线：**别人 clone 下来必须能跑通**。凡是依赖「只有某个服务商/某个账号才有」的能力，都不该出现在 `src/` 里——那会让仓库看起来能用、实际跑不通。

但那些能力对写作者本人往往是刚需。硬删掉是把自己弄残，硬留着是把别人坑了。折中办法就是这里。

## 已知被排除的能力

| 能力 | 为什么排除 | 原实现依赖 |
|---|---|---|
| 流式云端 ASR | 需要 `qwen3-asr-flash-realtime` 这类只在部分服务商提供的模型，别人未必有 | OpenAI Realtime 协议（WebSocket）+ 特定模型名 |
| 题解自动插入 | 内容是私人做题记录，不是通用工具 | 按题号匹配笔记段落 |
| 配图自动插入 | 图与题的映射是私人的 | 手工维护的映射表 |

`docs/asr-dead-ends.md` 里保留了流式方案的协议要点，需要时照着写一份放进来即可。

## 用法

```bash
# 放进来的脚本，直接用解释器跑，不用装进包
python private/my_stream_asr.py BVxxxxxxxxxx 4

# 想让它也出现在统一入口里，可以在本机改 src/bili_notes/cli.py 临时加一行，
# 但别提交那个改动。
```

## 一条规矩

`private/` 里的脚本**不要 import 包内私有名字**（下划线开头的函数），否则上游一改就断。只用 `common` 的公开函数（`view` / `playurl` / `api` / `get_raw` / `WORKDIR` / `FFMPEG`）就够覆盖绝大多数需求。
