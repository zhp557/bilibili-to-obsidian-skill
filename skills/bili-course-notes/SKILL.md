# B 站课程 → 结构化笔记

一集视频变成一篇可复习的笔记：**拿文本（字幕优先、ASR 兜底）→ 按讲解原意写成直陈正文 → 板书截图原样嵌入 → 时间轴与双链 → 脚本验收**。

## 何时用

- 用户给 B 站链接 / BV 号，说「总结并写进笔记」
- 用户说「继续做第 N 讲 / pN」「把笔记里没有的补上」
- 「补上」类请求 → 先做缺口盘点，只写缺的，别重写已有的

## 第 0 步：先盘点，再动手

```bash
bili-notes probe BVxxxx        # 有多少分 P、哪些是广告片尾、最高清晰度
```

再列一张表：`分 P ↔ 讲号 ↔ 已有/缺失`，先给用户看缺口，再开写。

**讲号 ≠ 分 P 号。** 命名前用「上一讲 + 章节号」交叉校验——曾经把 p9 误写成第 07 讲。广告和片尾不算讲，要在表里标出来。

## 拿文本：四档优先级（本流程最大的效率点）

| 档 | 手段 | 何时用 | 34 分钟一集（单次样本） |
|---|---|---|---|
| 1 | `bili-notes subs scan\|fetch` | **先扫，有就用** | 约 3 秒（单次样本） |
| 2 | `bili-notes http-asr` | 没字幕时首选，带标点、可读性最好 | 约 3 分钟（19 段串行） |
| 3 | `bili-notes asr` | 断网 / 不想花额度 | 6~10 分钟 |

**四档产物形态不同，写法也不同：**

| 来源 | 形态 | 写笔记时 |
|---|---|---|
| 字幕 `pNNN.txt` | `[mm:ss] 短句`，2~5 秒一条，几无标点 | 需要自己在脑内拼句；**结构可信，数值要查板书** |
| `http_asr` txt | `[mm:ss] 整段`，120 秒一条，**带标点** | 直接可读，接近逐字稿 |
| whisper `pN_transcript.txt` | 整段，窗口合并 | 同云端，但同音错字更多 |

判断 cookie 是否有效：`subs fetch` 报 `no sub` / `with_sub=0` → 看 `docs/cookies.md`。

## 六步主流程

| 步 | 命令 | 产物 |
|---|---|---|
| 1 | `probe BV PAGE` | 分 P、时长、最高分辨率、音频流 |
| 2 | `subs scan/fetch` → 没字幕则 `http-asr` | `work/subs_BV.../pNNN.txt` 或 `work/asr_http/BV_pN.txt` |
| 3 | `capture BV PAGE 0:<时长>:120` | `work/frames/<BV>/pN/t0000.png`（帧名带 t） |
| 4 | `contact pN` | `work/contact_pN.png` 联系表，一眼看结构 |
| 5 | `shots PAGE "<附件目录>" "秒:文件名.png" ...` | 中文命名附件 |
| 6 | `verify "<笔记.md>" "<附件目录>"` | PASS / 缺图 / 断链 / 体量 |

**截帧节奏**：先 120 秒一帧粗扫（34 分钟约 17 帧，一张联系表装得下），按联系表划出「开场 / 例题 / 解答 / 下一题」，再只为这些节点精挑 8~12 帧。不必每 30 秒都截，笔记里没人看那么多图。

本地 whisper 路线的 txt 要另跑一步 `extract pN` 生成。

## 合集不是分 P

`probe` 报 `PAGES: 1` 时先怀疑这是合集里的一集。全集在 `view` 接口的 `ugc_season.sections[].episodes[]` 里（每项有 `bvid` / `title` / `duration`）。

```python
import sys, pathlib
sys.path.insert(0, str(pathlib.Path("src").resolve()))
import bili_notes.common as C
d = C.view("BVxxxxxxxxxx")
s = d.get("ugc_season")
eps = [e for sec in s["sections"] for e in sec["episodes"]] if s else []
print(len(eps), sum(e["duration"] for e in eps) // 3600, "h")
```

**先把过滤后的集号列表给用户看再动手。** 一次 9 集里真正要做的可能只有 6 集，其余是广告与重复内容。不问就做，等于白跑三集。

多集并行的正确顺序：

1. 先手工把第 1 集完整走一遍，修到 PASS。这一集是样板。
2. 再一个子代理一集。brief 里写死：字幕文件绝对路径、附件目录名、脚本路径、结构口径，以及「先看图再落笔」。
3. 不要一次并行超过 8 个。

## 笔记骨架

```markdown
# 第NN讲 标题

> 视频：BVxxx 第 N P ｜ 时长 MM:SS ｜ UP 主：xxx
> 链接：https://www.bilibili.com/video/BVxxx/?p=N
> 整理方式：B 站 AI 字幕（N 条 / N 字）按讲解原意整理，公式为 LaTeX；题面数值以截图为准

![[01-本讲标题.png]]

## 本讲定位        ← 表格：题型 / 内容 / 这块要解决什么（写结论，别抄原话）
## 题型 1：…
### 这一类的 N 个要点
### 第 1 步 / 第 2 步 …
## 本讲小结        ← 表格：题型 / 触发特征 / 核心方法 / 易错点
## 时间轴          ← 每条 - [m:ss](https://www.bilibili.com/video/BVxxx/?p=N&t=秒) 描述
## 关联            ← [[上一讲]] / [[下一讲]] / 习题双链
```

写作要求：

- **详细优先**：写推导过程、原理、易错点，不能只给结论
- 公式一律 LaTeX：行内 `$...$`，独占 `$$...$$`
- 易错点用标注：`==🔴口诀：…==`、`==🟠分母必须非零。==`
- 数值读不准写「以截图为准」，不要硬猜
- 每篇 5~15 KB；低于 4 KB 通常是压缩过头
- 时间轴 15~25 条，全部带 `?p=N&t=秒` 跳转

### 讲述口径：意译优先，不堆原话

判据只有一条：**这句原话比转述更省时间吗？**

1. 不是「不许引用」，是「引用要有用」。老师自创的比喻、口诀、当场踩过的坑、改卷口径——留着；只是把概念重说一遍的，写成直陈句。
2. **禁止夹心结构**（先抄一段原话 → 再跟一句点评）。每节改成：结论先行 → 原理用大白话展开 → 判据/口诀收口。
3. 转述框架一起去掉。除了要交代「这段是旧版录像 / 这页是板书原文」，不写「老师强调」「老师特意说」。
4. **删掉的必须补**：原话里承载的知识点在原位用直陈句补回来，不能只删不补。
5. 单处别超 3 行。超过就是在整段搬运。

## 输出格式：Markdown / PDF

- **默认交付 Markdown（`.md`）**：按上面的笔记骨架整理，保留 LaTeX 公式、板书截图、可跳转的视频时间轴和 Obsidian 双链。
- **用户要求 PDF（`.pdf`）时**：先生成并验收 Markdown 底稿，再用可用的导出工具生成 PDF。检查导出后的公式、图片和分页，尽量保留可点击的视频时间轴链接；Obsidian 双链不要求在 PDF 中可用。
- **没有可用的 PDF 导出工具时**：交付 `.md` 并明确说明未生成 PDF。用户可在 Obsidian 桌面版打开笔记，从右上角 `⋯` 菜单选择「导出为 PDF」。`bili-notes` CLI 本身不负责导出 PDF。

## 验收

```bash
bili-notes verify "<笔记.md>" "<附件目录>"
bili-notes verify --dir "<笔记目录>" --att "<附件根目录>"
```

**脚本判定**（`verify` 给 PASS/CHECK，CHECK 时退出码非零）：

1. 图片引用数 = 附件数（缺图 = 裂图，多图 = 白截）
2. 双链无断链
3. 体量 ≥ 下限（默认 5 KB；习题类 2 KB）

**人工复核**（脚本不判，别假装它判了）：

4. 体量是否超过 20 KB、时间轴是否 ≥ 10 条（过少时脚本只打提示）
5. 讲号 = 上一讲 + 1；相邻讲的「上一讲 / 下一讲」双向链接是否指回来

细则与误伤说明见 `docs/pitfalls.md` 第 15 条（「时间轴 0 条」是提示不是失败）。

## 坑

完整 18 条在 [`docs/pitfalls.md`](../../docs/pitfalls.md)。最容易中招的四条：

1. 匿名请求只给 480P，带 cookie 才给 720P —— 板书想看清先确认 cookie。
2. AI 字幕稳定听错专业词与数值（`5/8` → `5%`）—— 结构按字幕，数值看截图。
3. 附件目录别用 `startswith('p1')`，会命中 `p10-`。
4. 别用脚本改 Obsidian 的 `appearance.json`，会被整体重写。
